Cài đặt JDK 17 hoặc 21, Apache NetBeans và SQL Server Express.
Giải nén thư mục dự án, mở NetBeans → File → Open Project → chọn thư mục LAB2_MaHoaHienDai
Nhấp phải project → Clean and Build, kiểm tra BUILD SUCCESS.
Nhấn F6 để chạy chương trình
Chọn các chức năng mã hóa, giải mã hoặc phân tích 
Để sử dụng chức năng lưu lịch sử, mở SSMS và chạy file 01_Tao_CSDL.sql để tạo database LAB2_MaHoaHienDai
Cấu hình SQL Server bật TCP/IP, sử dụng cổng 14333 và tạo tài khoản SQL có quyền truy cập bảng dbo.history.
Trong chương trình chọn Kết nối SQL Server, nhập thông tin tài khoản rồi nhấn Test Connection.
Sau khi mã hóa hoặc giải mã, chọn Xem lịch sử để kiểm tra dữ liệu đã lưu.
Có thể chạy file 03_Kiem_Tra_Du_Lieu.sql trong SSMS để xem kết quả lưu trữ.
